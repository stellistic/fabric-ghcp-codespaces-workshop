# Investigation and scoped change record

Use this in ignored local results; leave the tracked template empty.

| Category | Evidence |
|---|---|
| Desired outcome | Observable acceptance, not an implementation prescription |
| Context and constraints | Approved source, target, scope and excluded actions |
| Observations | Reproducible queries/commands, source version, actual values |
| Hypotheses | Alternatives not established by observations |
| SME questions | Semantics requiring an authorized expert |
| Proposed plan | Smallest change, affected files/items and expected output |
| Approval | Exact reviewed diff/hash and scope; no implied blanket permission |
| Execution | Actual commands/tools, error handling and stop conditions |
| Independent verification | Different oracle/query, before-fail and after-pass evidence |
| Rollback | Original definition, exact target and reviewed restoration procedure |
| Residual status | Offline-complete, live-pending, blocked or real-objective-incomplete |
