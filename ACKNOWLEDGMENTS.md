# Reuse and provenance

The repository owner supplied a prior synthetic workshop snapshot at commit
`d0d8c57a5dfc3d9eff8a2339c0266395367733df` for reuse. This implementation preserves
the K-Corp raw dataset, deterministic issue seeder, expected counts, focused
seeder tests, percent-format notebook sources and notebook-generation approach.
The source repository was read-only throughout adaptation.

Adaptations include browser-first GitHub Copilot tasks, canonical dictionary
and deliberately imperfect vendor claims, an independent offline curation
reference, monthly SQL/filter regression, explicit notebook/workspace/model
approval guards, utility-free core modeling, guarded live adapters, and new
facilitator/participant materials. Synthetic plant-manager labels were replaced
with fictional role placeholders; illustrative notification addresses were
changed to `example.invalid`.

Old event guides, dates, tenant assumptions, browser capture tooling,
screenshots and recordings are not default participant assets. No historical
Copilot transcript, customer requirements, internal correspondence, successful
live test, or provisioned Fabric resource is claimed or reproduced.

GitHub Copilot CLI, Fabric CLI, Python packages, Semantic Link Labs, Delta,
Apache Spark and the devcontainer base retain their respective licenses and
trademarks. Product access, runtime dependencies and redistribution rights are
separate from permission to use this private training repository.
